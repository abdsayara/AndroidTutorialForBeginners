# مختبر الرياضيات التفاعلي — Interactive Mathematics Simulation Lab

تطبيق ويب تعليمي عربي (RTL) يحوّل قوانين ومفاهيم **كتاب الرياضيات للصف العاشر (دولة فلسطين، الطبعة الرابعة 2026م)** إلى 29 محاكاة تفاعلية.
المطوّر: [عبدالرحمن سياعره](https://www.linkedin.com/in/abd-sayara)

كل المحتوى مأخوذ من الكتاب، مع رقم الوحدة والدرس والصفحة داخل كل محاكاة. أي إثراء بصري خارج الكتاب مُعلَّم بوضوح.

## التشغيل

```bash
cd math-lab
python3 -m http.server 8765      # ثم افتح http://127.0.0.1:8765
```

لا يحتاج خطوة بناء ولا اتصالاً بالإنترنت (KaTeX مضمّن في `vendor/katex`). لبناء نسخة من ملف واحد للمشاركة: `python3 tools/bundle.py` ← `dist/math-lab.html`.

## المحتوى (حسب فهرس الكتاب)

| الوحدة | المحاكيات |
|---|---|
| 1 المنطق الرياضي | جداول الصواب وأدوات الربط (مع تشبيه الدارة الكهربائية)، العبارات المتكافئة |
| 2 الاقترانات ورسومها | الانسحاب، الانعكاس، الاقتران التربيعي وإشارته، إشارة الخطي والنسبي، المتباينات، متعدد القاعدة، القيمة المطلقة، أكبر عدد صحيح، الأسي، اللوغاريتمي |
| 3 الدائرة | معادلة الدائرة، الزوايا المركزية والمحيطية والمماسية، الرباعي الدائري |
| 4 الاقترانات المثلثية | الوضع القياسي، الراديان، دائرة الوحدة (مع موجتي الجيب وجيب التمام)، التمثيل البياني، المتطابقات، المعادلات |
| 5 المصفوفات | العمليات، الضرب (عددي وهندسي)، المحدد والنظير الضربي، قاعدة كريمر |
| 6 العد | مبدأ العد والمضروب، التباديل، التوافيق، نظرية ذات الحدين |

كل محاكاة فيها: الصيغة (KaTeX) وترميز الكتاب، جدول المتغيرات ومجالاتها، أدوات تحكم (منزلق + إدخال)، رسم Canvas حي مع سحب/تكبير ونقاط قابلة للسحب، نتائج وخطوات، «ماذا حدث؟ ولماذا؟»، أزرار إعادة الضبط/التشغيل/قيم عشوائية، أوضاع **تعلّم / استكشف / تحدٍّ**، و**مساعد الرياضيات الذكي** (محلي، يجيب من القيم الحالية).

## الدقة والاختبار

- `npm test` — 18 مجموعة اختبارات تقارن الحسابات بمرجع مستقل بـ Python/NumPy (`tests/reference.py`): الجذور والمميز (300 حالة)، المحددات والنظير (200)، كريمر (200)، التوافيق/التباديل/المضروب حتى 20، قيم المثلثات كل 15° من −720° إلى 720°، اللوغاريتمات، أكبر عدد صحيح (حسابات كسرية دقيقة)، 2000 حالة عشوائية لنظرية الزاوية المحيطية، 1000 رباعي دائري، حلول المعادلات المثلثية، القسمة على صفر وخطوط التقارب والثقوب.
- `npm run e2e` — يفتح كل محاكاة في Chromium على مقاسات هاتف/تابلت/حاسوب، يحرّك كل منزلق إلى أدناه وأعلاه وقيم وسطى، يضغط كل زر وكل وضع وكل تحدٍّ وكل سؤال مقترح للمساعد، ويتحقق من عدم وجود أخطاء أو `NaN` أو تمرير أفقي.
