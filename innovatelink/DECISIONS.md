# DECISIONS

قرارات تقنية وانحرافات عن القسم 4 من الـ PRD، مع المبرر. (PRD instruction 2: any library outside §4 needs a written justification.)

| # | القرار | المبرر |
| --- | --- | --- |
| D-1 | **جلسات قاعدة بيانات مكتوبة يدوياً بدل Auth.js** (`lib/auth/session.ts`). | مزوّد Credentials في Auth.js لا يدعم جلسات قاعدة البيانات (يفرض JWT)، بينما الـ PRD يطلب credentials + جلسات في قاعدة البيانات + انتهاء بعد 7 أيام خمول + قفل بعد 5 محاولات. التنفيذ صغير (~60 سطراً): توكن عشوائي 256-bit، يُخزَّن hash فقط، كوكي HttpOnly/SameSite=Lax/Secure، انتهاء منزلق. |
| D-2 | **`@node-rs/argon2`** | تنفيذ argon2id أصلي سريع بلا اعتماديات بناء (PRD §9). |
| D-3 | **قوالب بريد HTML بسيطة بدل React Email** (`lib/mail`). | رسائل المعاملات قليلة (تأكيد، استعادة، إشعارات)؛ قالب RTL واحد يكفي ويتجنب حزمتين إضافيتين. النصوص من `messages/*.json`. |
| D-4 | **مكونات بنمط shadcn/ui مكتوبة يدوياً** (`components/ui`) وTailwind 3. | shadcn/ui ينسخ الكود ولا يُثبَّت كحزمة؛ احتجنا 10 مكونات فقط. خصائص منطقية (`ps-/me-/start/end`) لدعم RTL. |
| D-5 | **`aws4fetch`** لتوقيع روابط S3 بدل AWS SDK. | 6KB مقابل عشرات الميغابايت؛ يكفي لـ presigned PUT/GET وقراءة رأس الملف. |
| D-6 | **`unpdf` + `fflate`** لاستخراج نص PDF/DOCX. | FR-5.1 و§7.3 يتطلبان استخراج النص؛ unpdf يغلف pdf.js دون اعتماديات أصلية، وDOCX ملف zip نقرأ منه `word/document.xml`. |
| D-7 | **`playwright-core` + Chromium لتصدير PDF** (`lib/pdf`). | معيار القبول: «PDF يعرض العربية من اليمين لليسار بخط صحيح». مكتبات PDF في JS لا تشكّل الحروف العربية ولا تدعم bidi؛ Chromium يفعل. صورة Docker تثبّت `chromium`. |
| D-8 | **`@fontsource/ibm-plex-sans-arabic`** | استضافة الخط ذاتياً (لا طلبات لـ Google، يتوافق مع CSP)، ويُضمَّن في PDF كـ data URI. |
| D-9 | **عمود `vector` بلا بُعد ثابت** | يسمح بضبط `EMBEDDING_DIM` من البيئة دون ترحيل. الثمن: لا فهرس HNSW/IVFFlat. عند حجم MVP (مئات–آلاف السجلات) المسح الكامل سريع. عند تثبيت النموذج: ترحيل إلى `vector(N)` وإضافة `CREATE INDEX ... USING hnsw (embedding vector_cosine_ops)`. |
| D-10 | **محدِّد معدل في الذاكرة** (`lib/auth/rate-limit.ts`). | الـ PRD يحدد خادماً واحداً؛ لا حاجة لـ Redis. يُضبط حد `/auth/*` بـ `AUTH_RATE_LIMIT_PER_MIN`. |
| D-11 | **CSRF عبر فحص `Origin`** + `SameSite=Lax`. | الـ API لا يقبل إلا JSON من نفس الأصل؛ فحص Origin على كل طلب يغيّر الحالة أبسط من توكنات مزدوجة ومكافئ له هنا. |
| D-12 | **مزوّد embeddings وهمي دلالي** (`lib/ai/providers/mock.ts`). | تجزئة جذوع الكلمات العربية (مُطبَّعة) + معجم مفاهيم صغير، ليعمل البحث الدلالي ومعايير القبول دون مفاتيح API. **تقييم النماذج الحقيقية (مخاطرة §11) لم يُجرَ بعد**. الإجراء المقترح: شغّل `npm run db:seed` مع كل نموذج مرشّح (مثلاً `text-embedding-3-small` و`multilingual-e5-large` عبر واجهة متوافقة مع OpenAI)، وقِس ترتيب المشروع الصحيح لكل تحدٍّ من الـ 15 (مقياس recall@3)، ودوّن النتيجة هنا. |
| D-13 | **محوّل LLM متوافق مع OpenAI + محوّل Anthropic**، تختارهما `LLM_PROVIDER`. | الواجهة المتوافقة تغطي معظم المزوّدين والنماذج المستضافة ذاتياً. أسماء المزوّدين محصورة في `lib/ai/`. |
| D-14 | **`zod-to-json-schema`** لتوليد `openapi.yaml`. | الـ PRD يطلب توليده من مخططات Zod. يُكتب كـ JSON (وهو YAML 1.2 صالح) لتجنب حزمة YAML. |
| D-15 | **`s3rver` (تطوير فقط)** لاختبارات E2E. | بديل S3 بـ Node عندما لا يتوفر MinIO؛ الإنتاج يستخدم MinIO في docker-compose. |
| D-16 | **pg-boss** للمهام الخلفية؛ في الاختبارات تُلتقط المهام في مصفوفة وتُستدعى المعالِجات مباشرة. | يبقي الاختبارات حتمية دون worker. |
| D-17 | **`AuditLog` إلحاقي على مستوى قاعدة البيانات** عبر trigger يمنع UPDATE/DELETE. | يضمن الخاصية حتى لو أخطأ الكود. |
| D-18 | **البحث المدمج** = اندماج الرتب التبادلي (RRF) بين نتائج النص (ILIKE + pg_trgm) ونتائج المتجهات. النتائج الدلالية التي لا يراها المستخدم إلا كعنوان معمّم تُستبعد. | يمنع استنتاج محتوى سري من تشابه المتجهات. |
| D-19 | **إعادة الترتيب بمعايير 0–5 والدرجة الكلية = متوسط مرجّح ÷ 5**، أوزان قابلة للتعديل من الإدارة وتُطبَّع لمجموع 1. التفسير الذي لا يذكر حقلاً من الطرفين يُكمَّل آلياً باستشهاد صريح. | §7.2. |
