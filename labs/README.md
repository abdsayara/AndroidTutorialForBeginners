# المختبرات التفاعلية — Interactive Simulation Labs

بوابة تعليمية عربية (RTL) مقسّمة حسب الصف ثم المادة. حالياً: **الصف العاشر ← الرياضيات | الفيزياء**، وهي مهيّأة لإضافة صفوف أخرى.
المطوّر: [عبدالرحمن سياعره](https://www.linkedin.com/in/abd-sayara)

| المختبر | المصدر الوحيد للمحتوى | العدد |
|---|---|---|
| مختبر الرياضيات التفاعلي | كتاب الرياضيات للصف العاشر (فلسطين، الطبعة الرابعة 2026م) | 29 محاكاة |
| مختبر الفيزياء التفاعلي | كتاب الفيزياء للصف العاشر (فلسطين، الطبعة الثالثة 2020م) | 31 تجربة |

كل محاكاة تعرض المصدر (الوحدة/الفصل، الدرس، الصفحة). أي إثراء بصري خارج الكتاب مُعلَّم بوضوح.

## التشغيل

```bash
cd labs
python3 -m http.server 8765      # ثم افتح http://127.0.0.1:8765
```

لا يحتاج خطوة بناء ولا اتصالاً بالإنترنت (KaTeX مضمّن في `vendor/katex`). نسخة من ملف واحد للمشاركة: `python3 tools/bundle.py` ← `dist/labs.html` (و `--artifact` لنسخة Artifact).

المسارات: `#/g10/math` ، `#/g10/physics` ، `#/g10/<math|physics>/sim/<id>`.

## صيغة الكتاب العربية

تُعرض كل الرموز والصيغ والمعادلات **بصيغة الكتابين العربية** افتراضياً: رموز عربية (ق(س)، س، ص، أ ب جـ، جا جتا ظا، لو، ق = ك × ت، ض = ث جـ ل، كح = ك حن Δد…)، **أرقام عربية** (٠١٢٣٤٥٦٧٨٩) والفاصلة العشرية «,»، **وحدات بالعربية** (نيوتن، كغم، م/ث²، باسكال، جول، كلفن، °س)، والمعادلة **من اليمين لليسار** كما في الكتاب (الأس على يسار الرمز، الكسور والجذور والمصفوفات معكوسة).
زر «ع | x» في الشريط العلوي يبدّل إلى الرموز الدولية (x, y, F = ma) ويُحفظ الاختيار؛ ويمكن فرضه بالرابط `?n=ar` أو `?n=intl`.

التنفيذ في `core/notation.js` طبقة عرض فقط (الحسابات لا تتغير): `ML.arTeX` يحوّل صيغ TeX إلى رموز الكتاب، و`ML.loc` يعرّب النصوص والرسوم (Canvas)، ثم تُعكس المعادلة أفقياً بعد KaTeX مع إعادة الحروف والأرقام. لكل محاكاة خريطة رموز خاصة اختيارية `ar` حين يختلف معنى الحرف (مثل W = الوزن «و» أو الشغل «ش»).

## الدقة والاختبار

```bash
npm test        # node --test tests/*.test.mjs
npm run e2e     # يحتاج الخادم المحلي يعمل
```

- `tests/math.test.mjs` — مقارنة حسابات الرياضيات بمرجع Python/NumPy (`tests/reference.py`).
- `tests/physics.test.mjs` — كل منزلق في كل تجربة عند الحد الأدنى والأعلى والمنتصف والصفر وكل خيار (مع تشغيل دوال الرسم والرسوم البيانية)، تشغيل كل تجربة زمنية حتى نهايتها، القسمة على صفر والحدود الفيزيائية، حلول تحديات أمثلة الكتاب، القيم العددية لأمثلة الكتاب المحلولة (مثلاً 2.5 م/ث²، 6×10⁵ Pa، 196 N، 20.85 °س، 68878 J، 602.4 سم³، 7.03 L، ΔU = 4500 J)، ومقارنة الصيغ بمرجع Python مستقل (`tests/physics_reference.py`).
- `tests/notation.test.mjs` — يتحقق أن صيغ ونتائج وخطوات كل المحاكيات تخلو من الرموز اللاتينية والأرقام الإنجليزية في صيغة الكتاب، وأنها تُعرض بـ KaTeX دون أخطاء.
- `tests/e2e.mjs` — يفتح كل محاكاة/تجربة في Chromium على مقاسات هاتف/تابلت/حاسوب، يحرّك كل منزلق، يشغّل ويوقف، يبدّل الرسوم البيانية والأوضاع والتحديات وأسئلة المساعد، ويتحقق من عدم وجود أخطاء أو `NaN` أو تمرير أفقي، ومن عدم ظهور أرقام إنجليزية في النصوص أو على الرسوم في صيغة الكتاب (`--intl` للوضع الدولي).

## البنية

```
index.html                    البوابة (توجيه بالـ hash)
css/app.css                   التصميم (فاتح/داكن، متجاوب)
core/math.js, fx.js           النواة الرياضية
core/notation.js              صيغة الكتاب العربية: الرموز والأرقام والوحدات والاتجاه
core/phys.js                  قوانين الفيزياء النقية وجداول الكتاب (الحرارة النوعية، معاملات التمدد…)
core/plot.js                  محرك الرسم الديكارتي (Canvas)
core/ui.js                    الصفوف والمواد، الصفحة الرئيسية، صفحة المحاكاة، المحرك الزمني والرسم الحي
core/tutor.js                 المساعد الذكي (رياضيات/فيزياء)
subjects/g10-math/unitN.js    محاكيات الرياضيات
subjects/g10-physics/*.js     تجارب الفيزياء
```

لإضافة صف جديد: أضِف عنصراً إلى `ML.grades` ومادته إلى `ML.subjects` في `core/ui.js`، ثم ملفات المحاكاة في `subjects/<grade>-<subject>/` وأدرجها في `index.html`.
