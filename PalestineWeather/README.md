# طقس فلسطين — Palestine Weather

تطبيق أندرويد عربي (من اليمين لليسار) لطقس فلسطين، مكتوب بـ Kotlin و Jetpack Compose.

## الشاشات

الشريط السفلي فيه خمسة تبويبات:

| التبويب | المحتوى |
|---|---|
| الرئيسية | الطقس الآن، الساعات القادمة، الرطوبة، الأشعة فوق البنفسجية، الشروق والغروب، جودة الهواء، توقعات 7 أيام |
| الخريطة | خريطة فلسطين بحدودها الحقيقية، مع السحب والتكبير. ست طبقات: الحرارة، الرياح، الأمطار، السحب، العواصف، الزلازل |
| المدن | بحث، فرز حسب المنطقة، المفضلة، تحديد أقرب مدينة لموقعك |
| الزراعة | ملاءمة الأيام للعمل في الأرض وقطف الزيتون، نصائح الري والرش، اختيار الإشعارات |
| المزيد | تفاصيل الساعات، أوقات الصلاة والقبلة، التنبيهات السابقة، الأخبار، أسعار العملات، مصادر البيانات |

كل ثلاث ساعات يفحص التطبيق في الخلفية (WorkManager) توقعات المدينة المختارة والزلازل الأخيرة. إذا وجد مطراً أو صقيعاً أو حراً أو رياحاً قوية أو هزة بقوة 3 فأكثر، يرسل إشعاراً ويحفظ التنبيه في السجل.

كل استجابة ناجحة من الإنترنت تُحفظ على الجهاز، فيعمل التطبيق دون اتصال ويعرض آخر بيانات مع شريط "غير متصل".

## مصادر البيانات (كلها مجانية وبدون مفتاح API)

| البيانات | المصدر |
|---|---|
| الطقس والتوقعات وشبكة الأمطار والسحب والعواصف | [Open-Meteo](https://open-meteo.com) |
| جودة الهواء | Open-Meteo Air Quality |
| الزلازل | [USGS](https://earthquake.usgs.gov/fdsnws/event/1/) |
| أوقات الصلاة | [Aladhan](https://aladhan.com/prayer-times-api) |
| أسعار العملات | [open.er-api.com](https://www.exchangerate-api.com/docs/free) |
| الأخبار | Google News RSS |
| حدود الخريطة | [Natural Earth](https://www.naturalearthdata.com) (ملكية عامة) |

راجع شروط استخدام كل مصدر قبل النشر التجاري. Open-Meteo مثلاً مجاني للاستخدام غير التجاري فقط.

**طبقة البروق:** لا يوجد مصدر مجاني لمواقع الصواعق الفعلية. لذلك طبقة "العواصف" تعرض مؤشر CAPE من نموذج الطقس، وهو يدل على احتمال العواصف الرعدية وليس رصداً للبرق. لعرض الصواعق الحقيقية تحتاج مزود بيانات تجارياً.

**الخريطة:** حدودها من Natural Earth بإسقاط يحافظ على النسب الحقيقية. حدود الجولان قُصّت بخط تقريبي. المولّد موجود في `app/src/main/java/ps/weather/ui/map/PalestineShape.kt`.

## التشغيل

1. افتح مجلد `PalestineWeather` في Android Studio (إصدار Koala أو أحدث).
2. انتظر مزامنة Gradle.
3. شغّل التطبيق على جهاز أو محاكٍ بأندرويد 8.0 (API 26) أو أحدث.

```
    ├── components/        الأيقونات وعناصر الواجهة المشتركة

    └── screens/           باقي الشاشات
```
