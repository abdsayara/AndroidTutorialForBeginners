# طقس فلسطين — موقع الويب

النسخة الويب من تطبيق «طقس فلسطين»: خادم Node.js وواجهة عربية من اليمين لليسار تعمل على الهاتف والحاسوب.
لا يحتاج المشروع أي مكتبات خارجية، فقط Node.js 20 أو أحدث.

## التشغيل

```bash
cd PalestineWeatherWeb
npm start          # بيانات حقيقية من المصادر — http://localhost:3000
npm run demo       # وضع العرض: بيانات تجريبية دون إنترنت، مع شريط تنبيه واضح في الأعلى
npm test           # الاختبارات
```

## الصفحات

| المسار | المحتوى |
|---|---|
| `/` | الطقس الآن، الساعات القادمة، الرطوبة والأشعة وجودة الهواء، توقعات 7 أيام |
| `/map` | خريطة فلسطين بحدودها الحقيقية مع السحب والتكبير (بالفأرة أو اللمس أو لوحة المفاتيح)، وست طبقات: الحرارة، الرياح، الأمطار، السحب، العواصف، الزلازل |
| `/cities` | بحث، فرز حسب المنطقة، المفضلة، تحديد أقرب مدينة لموقعك |
| `/farming` | ملاءمة الأيام لقطف الزيتون والعمل في الأرض، الري والرش، إعدادات الإشعارات |
| `/hourly` `/prayer` `/alerts` `/news` `/currency` `/about` | تفاصيل الساعات، أوقات الصلاة والقبلة، سجل التنبيهات، الأخبار، العملات، مصادر البيانات |

على الحاسوب تظهر قائمة جانبية، وعلى الهاتف شريط سفلي.

## الخادم

يجلب الخادم البيانات من المصادر ويوحّد شكلها ويحفظها:

- **في الذاكرة** لمدة قصيرة (من 10 دقائق إلى 6 ساعات حسب النوع)، فيشترك كل الزوار في طلب واحد للمصدر.
- **على القرص** في مجلد `data/`. إذا تعطّل مصدر، يُعرض آخر نسخة محفوظة مع تنبيه للمستخدم.
- **التنبيهات:** كل 3 ساعات يفحص توقعات كل المدن والزلازل الأخيرة، ويحفظ التنبيهات الجديدة في `data/alerts.json` لمدة 30 يوماً. يمكن للزائر تفعيل إشعارات المتصفح لها.

| الواجهة | الوصف |
|---|---|
| `GET /api/cities` | المدن والمناطق |
| `GET /api/forecast?city=jerusalem` | التوقعات لمدينة |
| `GET /api/air?city=…` | جودة الهواء |
| `GET /api/now` | الطقس الآن لكل المدن (لطبقات الخريطة) |
| `GET /api/grid` | شبكة الأمطار والسحب وCAPE فوق فلسطين |
| `GET /api/quakes?days=1\|7\|30` | الزلازل |
| `GET /api/prayer?city=…&method=5\|3\|4\|23` | أوقات الصلاة والقبلة |
| `GET /api/rates` | أسعار العملات مقابل الشيكل |
| `GET /api/news?topic=weather\|climate\|farming` | الأخبار |
| `GET /api/alerts` | سجل التنبيهات |

المتغيرات: `PORT` (افتراضي 3000)، `DATA_DIR` (افتراضي `./data`)، `DEMO=1` لوضع العرض، `ALERTS=off` لإيقاف فحص التنبيهات.

## النشر

```bash
docker build -t palestine-weather-web PalestineWeatherWeb
docker run -p 3000:3000 -v pw-data:/data palestine-weather-web
```

أو على أي خدمة تشغّل Node.js (مثل Render أو Railway أو Fly.io أو خادم VPS): الأمر `npm start` من داخل مجلد `PalestineWeatherWeb`. يُستحسن ربط مجلد `data/` بقرص دائم ليبقى سجل التنبيهات بعد إعادة التشغيل.

## النشر على Vercel

الملف `vercel.json` ومجلد `api/` يجهّزان المشروع لـ Vercel: كل الواجهات تمر بدالة خادم واحدة `api/index.js` (الخطة المجانية تسمح بـ 12 دالة فقط) تستخدم نفس كود الخادم، والملفات الثابتة تُقدَّم من `public/`.
عند ربط المشروع اجعل **Root Directory** = `PalestineWeatherWeb` ولا تحدد إطار عمل (Framework: Other).

الفروق عن الخادم العادي:
- Vercel لا يحتفظ بالملفات بين الطلبات، لذلك **صفحة التنبيهات تعرض التنبيهات الحالية والقادمة** محسوبة من التوقعات عند الطلب، بدل سجل 30 يوماً.
- يُخزَّن رد كل واجهة في شبكة Vercel لمدة 10 دقائق، فيشترك الزوار في نفس الطلب.

## مصادر البيانات

Open-Meteo (الطقس، الشبكة، جودة الهواء)، USGS (الزلازل)، Aladhan (الصلاة)، open.er-api.com (العملات)، Google News RSS (الأخبار)، Natural Earth (حدود الخريطة). كلها بدون مفتاح API.
راجع شروط كل مصدر قبل الاستخدام التجاري. Open-Meteo مثلاً مجاني للاستخدام غير التجاري فقط.

طبقة «العواصف» تعرض مؤشر CAPE من نموذج الطقس، وهي تدل على احتمال العواصف الرعدية وليست رصداً للبرق.

## أحوال الطرق

صفحة `/roads` تقرأ رسائل مجموعات تلغرام العامة لأحوال الطرق كل دقيقتين، وتستخرج منها أسماء
الحواجز وحالتها (سالك / أزمة / مغلق) — انظر `server/roads.js`. المصادر الافتراضية:
`ahwalaltreq` و`a7walstreet` و`road_jehad`.

**المجموعات تحتاج واجهة تلغرام الرسمية بحساب** (القنوات وحدها لها صفحة ويب عامة):

1. ادخل https://my.telegram.org برقم تلغرام (يُفضّل رقم مخصّص لهذا الغرض) → API development tools،
   وأنشئ تطبيقاً لتحصل على `api_id` و`api_hash`.
2. على جهازك: `cd PalestineWeatherWeb && npm install && npm run telegram-login`، وأدخل المفتاحين
   والرقم والرمز الذي يصلك. يطبع البرنامج ثلاث قيم.
3. ضعها في Vercel → Settings → Environment Variables: `TG_API_ID` و`TG_API_HASH` و`TG_SESSION`،
   ثم أعد النشر. **لا تشارك `TG_SESSION`**: من يملكه يستخدم الحساب.

نأخذ نص الرسالة ووقتها فقط، لا اسم المرسل. بدون هذه القيم تعرض الصفحة «مصدر أحوال الطرق قيد الربط».

- لتغيير المصادر: `ROAD_CHANNELS="id:الاسم,id2:الاسم"`.
- لإضافة حاجز أو اسم بديل له: قائمة `CHECKPOINTS` في `server/roads.js` (المواقع تقريبية).
